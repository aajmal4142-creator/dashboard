# ClearESG 60-Day Sprint Plan (REVISED)

## Build Dashboard First, Then Polish Marketing

**Timeline**: 60 consecutive days (Days 1-60)  
**Strategy**: Complete dashboard product → Polish marketing & sales funnel  
**Target**: Ship fully functional dashboard, then add pricing/purchase flow  
**Team**: You + Claude Code (AI-assisted development)

---

## 📅 REVISED SPRINT BREAKDOWN

### PHASE 1: DASHBOARD — ENTERPRISE READINESS (Days 1-30)

Focus: Get the core product rock-solid for customers.

#### Days 1-5: ABAC Access Control

- Attribute-Based Access Control system
- Policy engine + audit logging
- Admin dashboard for policy management
- 3-4 week effort, unlocks enterprise deals

#### Days 6-10: CSV Import + OCR Data Extraction

- CSV template + parser
- OCR from PDFs (energy bills, invoices)
- Bulk datapoint creation
- 2-3 week effort, 70% faster onboarding

#### Days 11-15: Anomaly Detection Engine

- Year-over-year + peer benchmarking checks
- Confidence scoring
- Suggested actions for outliers
- 2-3 week effort, catches 80% of data quality issues

#### Days 16-20: Dashboard Polish (6 Improvements)

1. Emissions breakdown visualization (stacked bars, YoY trend, peer comparison)
2. Data quality scoring (% measured/estimated/missing)
3. Compliance roadmap (CSRD/BRSR timelines + checklist)
4. Anomaly alerts with suggested actions
5. Peer benchmarking heatmap
6. Report preview mode (draft compliance checklist)

#### Days 21-25: Custom Auth Migration Planning

- Design bcrypt + JWT + MFA system
- Database schema for sessions
- Migration plan from Clerk
- Implementation spec for Q3 2025

#### Days 26-30: Testing, Bug Fixes, Performance

- Integration testing (all features)
- Performance optimization (caching, queries)
- Bug fixes from QA
- Production readiness

---
