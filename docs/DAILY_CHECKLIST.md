# Daily Standup Checklist (Print This)

## Use this checklist every morning to track progress

---

## ☀️ MORNING (5 minutes)

- [ ] Read Day X from `60DAY_SPRINT.md`
- [ ] Check deliverables for today (3-4 items max)
- [ ] Estimate hours needed
- [ ] Prepare Claude Code prompt
- [ ] Set calendar reminder for end-of-day review
- [ ] Open GitHub to commit code

---

## 🔨 BUILDING (During day)

**Time blocks** (adjust based on task):

- [ ] 9:00 AM - 12:00 PM: Build Phase 1 (3 hours)
- [ ] 12:00 PM - 1:00 PM: Break/Lunch
- [ ] 1:00 PM - 5:00 PM: Build Phase 2 (4 hours)
- [ ] 5:00 PM - 6:00 PM: Testing + QA (1 hour)

**For each deliverable:**

- [ ] Claude Code prompt ready
- [ ] Start building
- [ ] Test locally
- [ ] No console errors
- [ ] Responsive design checked (mobile + desktop)
- [ ] Commit to git with clear message
- [ ] Mark deliverable as ✅ in tracking sheet

---

## 🌙 EVENING (10 minutes)

**Review today's work:**

- [ ] All deliverables complete? (Y/N)
- [ ] Code tested? (Y/N)
- [ ] Committed to git? (Y/N)
- [ ] Hours logged? (Y/N)
- [ ] No broken tests? (Y/N)

**Update tracking:**

- [ ] Add today's date
- [ ] Mark status: ✅ Complete or 🔄 In Progress
- [ ] Log actual hours vs. estimated
- [ ] Note any blockers or issues
- [ ] Review tomorrow's deliverables

**Tomorrow prep:**

- [ ] Read Day X+1 deliverables
- [ ] Prepare Claude Code prompt
- [ ] Check dependencies (anything blocking?)

---

## 📊 WEEKLY REVIEW (Every Friday)

- [ ] Review Days 1-5 (or 6-10, etc.)
- [ ] Calculate velocity: Hours spent vs. planned
- [ ] Identify blockers (if any)
- [ ] Celebrate wins 🎉
- [ ] Adjust next week if needed
- [ ] Update leadership on progress
